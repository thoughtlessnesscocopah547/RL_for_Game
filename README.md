## 🧠 Technology Overview

The system uses advanced methods to interpret screen activity. These include:

* **Dual-Stream Processing:** The system separates the game value from the specific action benefit to improve decision accuracy.
* **Temporal Patterns:** The app tracks a sequence of frames to understand motion rather than looking at static images.
* **Real-time Adaptation:** The system learns from its mistakes while it plays, which helps it improve its strategy during long gaming sessions.
* **Efficient Sampling:** The software focuses on important moments in the game, ignoring boring frames where nothing changes.

## 💡 Troubleshooting

If the software does not detect your game, verify that your game window is visible on your primary monitor. 

If the AI acts erratically, check your input settings. Ensure that no other controllers or joysticks are plugged into your computer, as these might conflict with the software's virtual input signals.

To reset the AI's learning, use the "Clear Cache" button in the Settings menu. This deletes the old memory and forces the system to start from scratch. This is helpful if you move from one game to a different game. 

Keep your computer plugged into a power source while the software runs. Training these models consumes hardware resources, which may drain laptop batteries quickly. If you experience heat issues, ensure your PC fans have space to circulate air.
